# dogevideos.fyi

Static homepage + privacy policy for the Google OAuth consent screen ("Dogevideos App" - the
`yt-ai-pipeline` hub). Two plain HTML files, no build step. Served by GitHub Pages at
`dogevideos.fyi` (see `CNAME`).

- `index.html` - what the app is, who uses it.
- `privacy.html` - what data it accesses and how it is handled.
