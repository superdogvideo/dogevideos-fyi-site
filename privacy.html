Privacy Policy

Dogevideos App · last updated 2026-09-25

Dogevideos App is a personal, single-owner tool. It is used exclusively by its own developer and owner to manage their own YouTube, TikTok and Instagram accounts. This policy explains what data the application accesses and how that data is handled - there is no wider audience, because no one else uses it.

What data this application accesses

The application signs in with each platform's own OAuth to the owner's own account there, and requests only the scopes it needs for that platform, all limited to the owner's own channel/account:

YouTube Data API v3:

  • youtube.upload - to upload videos the owner produced to their own channel.
  • youtube.readonly - to read the owner's own channel and video statistics (views, likes, subscriber count, video list) for a personal dashboard.
  • youtube.force-ssl - to read comments on the owner's own videos and, only after the owner reviews and confirms each individual action inside the application, to reply to or hide/approve/reject a comment.

TikTok Login Kit / Content Posting API (videos are uploaded as private/self-only until the developer app is approved for public posting):

  • user.info.basic - to identify the owner's own TikTok account.
  • video.upload, video.publish - to upload the owner's own produced videos to their own TikTok account.

Instagram Graph API (currently inactive while access is restricted at the platform level): reading the owner's own account and media statistics, and publishing the owner's own produced videos to their own account.

How the data is used and stored

All data read from any of these APIs (statistics, comments, video metadata) is stored only locally, on the owner's own computer, in a local database used to display trends and history inside the application. Nothing is uploaded to any third-party server, cloud service, or shared database.

What is never done

  • Data is never sold, shared, or disclosed to any third party.
  • The application never posts, replies to, or moderates a comment, and never publishes a video publicly, without the owner personally reviewing and confirming that specific action first.
  • No advertising, no analytics/tracking pixels, no cookies are used by this application or by this website beyond what a static page inherently needs to be served.
  • The application is never used to access, and never requests access to, any account other than the owner's own.

Data retention and deletion

Locally stored data can be deleted at any time by the owner by deleting the application's local database file. Google account access can be revoked at any time from the owner's Google Account settings under Security → Third-party apps with account access.
